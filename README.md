this a personal project to learn .NET Core web API, in short this an API to help store data and information from a game called "Limbus Company" i chose this game to try and simulate how websites like wikis handle data, 
also because it provided the opportunity to implement: many-to-many, many-to-one relationships, and lastly to motivate me to keep working on it since i play the game from time to time.

i have learned how to add authentication to the API using jwt tokens stored in cookies also using user-secrets to hide data like the username and password of the data base and the jwt key, and have learned how to handle many-to-many relationships and mapping models and domain to a DTO using auto mapper and pagination.


currently i am working on a front-end to represent data from the API and to store data in it, at first i was going to use .NET Core MVC but i decided to use this opportunity learn angular as its is a common pairing, and it lets me treat the API as a real back-end. by forcing me to learn how to handle and secure JWT Tokens and consuming DTO's through models and services
