this a personal project to learn .NET Core web API, in short this an API to help store data and information from a game called "Limbus Company" i chose this game to try and simulate how websites like wikis handle data, 
also because it provided the opportunity to implement: many-to-many, many-to-one relationships, and lastly to motivate me to keep working on it since i play the game from time to time.

i have learned how to add authentication to the API using jwt tokens stored in cookies also using user-secrets to hide data like the username and password of the data base and the jwt key
